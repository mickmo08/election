## Provenance recorded for every ingested artefact

`raw_files`: source, URL (secrets redacted), publisher, retrieval time, SHA-256, size, content type, storage key (content-addressed, write-once), schema version, HTTP metadata. `ingestion_runs`: adapter key and version, parameters, idempotency key, raw file ids, stats, data-quality checks, status, error, trigger. Every derived contest, candidacy and result snapshot stores `source_id` and `ingestion_run_id`.
